# Structured Programming in C

This repository documents my progress in studying structured programming
and the C programming language.

The exercises focus on building a solid understanding of fundamental
programming concepts through practical implementation.

## Topics

- Functions
- Pointers
- Pointer arithmetic
- Pass-by-reference
- Dynamic memory allocation
- malloc
- calloc
- realloc
- free

## Purpose

The purpose of this repository is to practice C programming through
university exercises and progressively develop stronger problem-solving
and programming skills.
